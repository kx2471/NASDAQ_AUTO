# ⚠️ DANGER ZONE - 데이터 무결성 보호

## 🚨 중요 규칙

### 1. **trades.json 직접 수정 금지**
- trades.json 파일은 **절대로 직접 수정하지 않습니다**
- 스크립트를 통한 자동 수정도 **철저한 검증 후에만** 허용

### 2. **포트폴리오 업데이트 스크립트 작성 시 필수 검증**
- 실제 보유 수량 vs 매도 수량 검증
- 가격 데이터 정확성 검증  
- 계산 결과가 상식적으로 맞는지 확인

### 3. **재발 방지를 위한 체크리스트**
```
[ ] 매도 수량이 실제 보유 수량을 초과하지 않는가?
[ ] 가격 데이터가 정확한가? (소수점, 단위 확인)
[ ] 계산 결과가 예상 범위 내에 있는가?
[ ] 테스트 실행 후 실제 데이터에 적용하는가?
```

## 🔍 발생했던 문제들

### 2025-09-15 현금 잔고 오류 사건
**원인**: `scripts/update-portfolio.js`가 잘못된 데이터로 trades.json 수정
- TSLA 매도: 4.6주 보유인데 13.8주 매도 기록
- PL 매도: 31주 보유인데 93주 매도 기록  
- COIN 가격: 35.93 → 325.93 (소수점 위치 오류)

**결과**: 현금 잔고가 ₩270만원 → $4,365로 잘못 계산됨

**교훈**: 
- 스크립트 실행 전 반드시 테스트 데이터로 검증
- 실제 보유량과 계산 수량 대조 필수
- 상식적 범위를 벗어나는 결과는 즉시 검토

## 📋 안전한 데이터 수정 절차

1. **백업 생성**
   ```bash
   cp data/json/trades.json data/json/trades_backup_$(date +%s).json
   ```

2. **테스트 환경에서 검증**
   - 별도 테스트 파일로 스크립트 검증
   - check-balance.js로 계산 결과 확인

3. **실제 적용 전 검토**
   - 현금 잔고가 ₩200-300만원 범위인지 확인
   - 보유 주식 수량이 실제와 일치하는지 확인

4. **적용 후 즉시 검증**
   - check-balance.js 실행
   - 결과가 예상과 다르면 즉시 백업으로 복원
