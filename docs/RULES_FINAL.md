# 📜 중지 시점 규칙 전체 (2026-11-15 동결)

이 시스템의 규칙은 **누가 강제하느냐**에 따라 세 층으로 나뉜다. 재설계할 때 가장 중요한 구분이다.
LLM이 지키기로 '약속'한 규칙은 반복해서 깨졌고, 코드가 강제한 규칙은 한 번도 깨지지 않았다.

| 층 | 강제 주체 | LLM이 바꿀 수 있나 | 위반 이력 |
|---|---|---|---|
| A. 주문 가드레일 | `services/trading.ts executeOrder` | 불가 | 없음 |
| B. 자동 청산 | `jobs/watcher.ts` (매분, LLM 무관) | 불가 | 없음 (단, 집행기 버그 1건 — 아래) |
| C. 매매 규칙서 | Manager LLM이 읽고 따름, 주간회고 LLM이 매주 재작성 | **가능** | 다수 (LESSONS.md §3) |

## A. 주문 가드레일 (코드, 최후 관문)

모든 주문은 `trading.executeOrder`를 거치며, 하나라도 걸리면 거부된다.

1. `MANUAL_SYMBOLS`에 있는 사용자 수동 종목은 주문 금지
2. 미국 티커만 (KRX 심볼 거부)
3. `qty`와 `amount` 중 정확히 하나. 금액 주문은 MARKET 전용, 소수점 수량은 시장가 매도에만
4. **미국 정규장 시간에만** 주문 (프리·애프터마켓 금지)
5. LIMIT 가격이 현재가에서 `TOSS_MAX_PRICE_DEVIATION_PCT`(20%) 넘게 벗어나면 거부
6. 주문당 한도 `TOSS_MAX_ORDER_USD`(중지 시 $400), 24시간 누적 매수 한도 `TOSS_MAX_DAILY_BUY_USD`(중지 시 $400)
7. 매수 금액 ≤ 토스 매수가능금액, 매도 수량 ≤ 토스 매도가능수량
8. `TOSS_DRY_RUN`이 정확히 `'false'`가 아니면 전송하지 않음 (안전 기본값)

집행기(`executor.ts`) 보조 규칙: SELL 먼저 → BUY 나중. 조건부 진입은 현재가가 전일 종가/지정가 이하일 때만 BUY. 금액(amount) SELL은 기준가로 주수 환산하고, 환산 실패 시 거부한다 (11/09 EL 전량 매도 버그 수정, ef5f6e1).

## B. 자동 청산 (감시기, 매분)

| 트리거 | 조건 | 동작 |
|---|---|---|
| 손절 | 현재가 ≤ 실효 손절가(`effective_stop_loss`) | 전량 매도 |
| 최초 SL | 토스 평단 −8% | — |
| 조기경보 | 보유 3세션 이상(체결 세션=0), TP1 전, 평단 −5% → 실효 손절가로 끌어올림 | 전량 매도 (28f34f5, 11/14부터) |
| TP1 | 평단 +8% | 절반 매도 |
| TP2 | 평단 +15% | 잔량 매도 |
| 잔량 보호스톱 | TP1 이후 max(고점 −5%, 평단 +2%), 올리기만 | 전량 매도 |
| 마감 전 소수점 선제 청산 | 마감 직전 소수점 잔량이 트레일링 손절선 근처 | 매도 (조기경보선은 제외) |

끄는 법: `EARLY_WARNING_REALTIME=false`, 경보폭은 `EARLY_WARNING_PCT`(기본 5).

### 마지막 회고(11/15) 점검 메모
- 규칙 3 "5건" → "최근 청산된 5건(롤링)"으로 문구 변경. 20% 고정은 유지돼 완화는 아니다. 다만 롤링이면 오래된 손실이 빠지면서 해제가 빨라질 수 있다. 재개 시 그대로 쓸지 정할 것.
- 기존 5번(백지 평가)은 1번에 통합, 16번(예외 금지)이 새로 생겼다. 번호는 유지됐다.
- 규칙이 회고 상한(≤15)을 넘어 16개가 됐고, 문장 하나하나가 조건 여러 개를 품고 있다. 이것 자체가 교훈이다 (LESSONS.md §3).
